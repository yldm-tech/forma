It never opens, decrypts or calculates one: nothing outside tests calls OpenFile, OpenReader, GetRows, Rows, GetSlicers or CalcCellValue. govulncheck's call graph reaches the advisories' symbols through those writers (and, through interface calls it cannot resolve, from unrelated code). The fixes are only in untagged excelize commits; take them with the next excelize release.
GO-2026-6684 excelize Decrypt panics on a malformed OLE/CFB encrypted workbook; the server never reads a workbook, encrypted or not.
GO-2026-6688 excelize recurses without bound on mutually-referencing array formulas while calculating; the server never calculates a cell and writes every value as a literal, text that looks like a formula in a quote-prefixed cell.
