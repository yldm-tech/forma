## Running Forma locally

Setup instructions live with the code, where they stay in step with it:

- [README](https://github.com/yldm-tech/forma#readme) — prerequisites (Go, Node.js, pnpm, Docker) and the steps to get an instance running.
- [AGENTS.md](https://github.com/yldm-tech/forma/blob/main/AGENTS.md) — the working reference: layout, commands, conventions, the API contracts that must not change, and the testing policy.
- [CONTRIBUTING.md](https://github.com/yldm-tech/forma/blob/main/CONTRIBUTING.md) — how to raise an issue, and what a good pull request looks like.

The short version, from the repository root:

```bash
pnpm install
cp .env.example .env
make deps-up      # PostgreSQL, Valkey, SpiceDB, RustFS and Mailpit in Docker
make migrate      # the goose schema, then the job queue's tables
make seed         # optional: a demo organization to sign in to (admin@forma.yldm.ai / Password#123)
make dev-server   # the Go server on :3000
make dev-web      # the Vite dev server, the app at http://localhost:5173/app/, proxying the API to :3000
```

If something goes wrong, [GitHub Discussions](https://github.com/yldm-tech/forma/discussions) is the fastest way to get help from people who have hit the same thing.
