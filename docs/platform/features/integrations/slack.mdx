## Forma Cloud

1. Click on the `Configuration` tab in the left sidebar and then click on the `Integrations` tab and click on the `connect` button under the `Slack` card.

![Forma Integrations Tab](/images/platform/features/integrations/slack/integrations-tab.webp)

1. Now click on the "Connect with Slack" button to authenticate yourself with Slack.

![Connect Forma with your Slack Workspace](/images/platform/features/integrations/slack/connect-with-slack.webp)

1. You will now be taken to the Slack OAuth page where you can select the Slack channel you want to link with Forma and click on the "Allow" button.

![Slack OAuth Page](/images/platform/features/integrations/slack/slack-auth.webp)

1. Once you have selected the account and completed the authentication process, you will be taken back to Forma Cloud and see the connected status as below:

![Forma is now connected with Slack](/images/platform/features/integrations/slack/slack-connected.webp)

<Note>
  Before the next step, make sure that you have a Forma Survey with at
  least one question and a Slack channel in the Slack workspace you integrated.
</Note>

1. In order to make your channel available in channel dropdown, you need to add forma integration bot to the channel you want to link. You can do this by going to channel settings -> Integrations -> Add apps -> Search for "Forma" -> Select the bot -> Add.

![Click on three dot at top right of the channel](/images/platform/features/integrations/slack/add-slack-bot-1.webp)

![Select Edit Settings](/images/platform/features/integrations/slack/add-slack-bot-2.webp)

![Navigate to Integrations](/images/platform/features/integrations/slack/add-slack-bot-3.webp)

![Add Forma Bot](/images/platform/features/integrations/slack/add-slack-bot-4.webp)

1. Now click on the "Link channel" button to link a Slack channel with Forma and a modal will open up.

![Link Forma with a Slack Channel](/images/platform/features/integrations/slack/link-survey-with-channel.webp)

1. Select the channel you want to link with Forma and the Survey. On doing so, you will be asked to select the questions' responses you want to feed in the Slack channel. Select the questions and click on the "Link Channel" button.

![Select question to link with Slack Channel](/images/platform/features/integrations/slack/link-with-questions.webp)

1. On submitting, the modal will close and you will see the linked Slack channel in the list of linked Slack channels.

![List of linked Slack Channels](/images/platform/features/integrations/slack/list-linked-surveys.webp)

Congratulations! You have successfully linked a Slack channel with Forma. Now whenever a response is submitted for the linked survey, it will be automatically sent to the linked Slack channel.

## Setup in self-hosted Forma

Enabling the Slack Integration in a self-hosted environment requires a setup using slack workspace account and changing the environment variables of your Forma instance.

<Note>
  If you are running Forma locally:

  You need to use `https` instead of `http` for the redirect URI.

  * You can update the `go` script in your `apps/web/package.json` to include the `--experimental-https` flag. The
    command will look like: <br />

    ```bash
      "go": next dev --experimental-https -p 3000
    ```

  * You also need to update the .env file in the `apps/web` directory to include the `WEBAPP_URL` as `https://localhost:3000` instead of `http://localhost:3000`.

  * You also need to run the terminal in admin mode to run the `go` script(to acquire the SSL certificate). You can do this by running the terminal as an administrator or using the `sudo` command in Unix-based systems.
</Note>

1. Create a Slack workspace if you don't have one already.

2. Go to the [Your apps](https://api.slack.com/apps) page and **Create New App**.

3. Click on **From Scratch** and provide the **App Name** and select your workspace in **Pick a workspace to develop your app in:** dropdown. Click on **Create App**.

4. Go to the **OAuth & Permissions** tab on the sidebar and add the following **Bot Token Scopes**:

   * `channels:read`

   * `groups:read`

   * `chat:write`

   * `chat:write.public`

   * `chat:write.customize`

5. Add the **Redirect URLs** under **OAuth & Permissions** tab. You can add the following URLs:

   * If you are running forma locally, you can enter `https://localhost:3000/api/v1/integrations/slack/callback`.

   * Or, you can enter `https://<your-public-facing-url>/api/v1/integrations/slack/callback`

6. Now, click on **Install to Workspace** and **Allow** the permissions.

7. Go to the **Basic Information** tab on the sidebar and copy the **Client ID** and **Client Secret**. Copy them and set them as the environment variables in your Forma instance as:

* `SLACK_CLIENT_ID` - OAuth Client ID

* `SLACK_CLIENT_SECRET` - OAuth Client Secret

1. Now, you need to enable the public distribution of your app. Go to the **Basic Information** tab and click on the **Manage distribution** button and click on the "Distribute App".

2. Scroll down to the **Share your app with other workspaces** section, complete the checklist and click on the **Activate public distribution** button.

### By now, your environment variables should include the below ones:

* `SLACK_CLIENT_ID`

* `SLACK_CLIENT_SECRET`

Voila! You have successfully enabled the Slack integration in your self-hosted Forma instance. Now you can follow the steps mentioned in the [Forma Cloud](#forma-cloud) section to link a Slack workspace with Forma.

## Remove Integration with Slack Workspace

To remove the integration with Slack Workspace,

1. Visit the Integrations tab in your Forma Cloud dashboard.

2. Select "Manage" button in the Slack card.

3. Click on the "Delete Integration" button.

4. It will now ask for a confirmation to remove the integration. Click on the "Delete" button to remove the integration. You can always come back and connect again with the same Slack Workspace.

![Delete Slack Integration with Forma](/images/platform/features/integrations/slack/delete-connection.webp)
