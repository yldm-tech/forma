## Introduction

Forma's server is Go with [gin](https://gin-gonic.com/), [GORM](https://gorm.io/) and [wire](https://github.com/google/wire); its admin UI is a React single-page app with [TanStack Router](https://tanstack.com/router) and [TanStack Query](https://tanstack.com/query), styled with [Tailwind CSS](https://tailwindcss.com/). [AGENTS.md](https://github.com/yldm-tech/forma/blob/main/AGENTS.md) is the binding reference; this page summarises how each framework is used.

## Server

### gin

- Every feature registers its routes from its handler; `server/internal/app/router.go` mounts them on groups that carry the conventions: `/api/app` (session, CSRF check, JSON error envelope), `/api/v3` (session or API key, RFC 9457 problems, the api:v3 rate limit) and the public paths forma2 defined.
- Handlers validate input at the boundary (`httpapi.BindJSON` with `binding` struct tags), read the caller with `httpapi.ActorFrom`, and pass every error to `httpapi.Fail`. Services return expected failures as `*apperr.Error`; anything else reaches the client as a generic 500.

### GORM

- GORM runs queries; it never migrates. The schema belongs to the goose migrations in `server/migrations/`.
- Repositories write plain SQL where it is clearer than the query builder, always with bound parameters.
- A change and the background jobs it causes commit together: run the change in `jobs.Enqueuer.Transaction` and enqueue with its `Tx.Enqueue`.

### wire

- `server/internal/app/wire.go` declares the dependency graph; `wire_gen.go` is generated (`make generate`) and committed, and CI fails when it is stale.
- Prefer a function to an interface; add an interface only where there are two implementations or a test seam.

## Admin UI

### TanStack Router

- Routes are files under `web/src/routes/`; `routeTree.gen.ts` is generated by the router plugin and committed.
- A route's loader prefetches the data its page needs through the same `queryOptions` factories the components read with.

### TanStack Query

- Server state lives in the query cache only; components do not keep a second copy of it in state.
- Calls go through `api` in `web/src/lib/api.ts`, which sends the CSRF header and throws `ApiError`.
- Mutations invalidate the queries whose data they change.

### Internationalization

- User-facing text goes through i18next (`useTranslation`, `t("<namespace>.<key>")`) with the catalogues in `web/locales/`. The `emails` namespace is rendered by the Go mailer from an embedded copy.

## Tailwind CSS

We use Tailwind as intended; see the [Tailwind CSS guidelines](https://tailwindcss.com/docs/styling-with-utility-classes). Tailwind 4 only scans the consuming app's own sources, so packages ship their own CSS (`@forma/survey-ui/styles`; `@forma/surveys` inlines its styles into the bundle).
