This page documents naming choices that intentionally split similar-sounding terms
across different domains. Always check this list before introducing a name that
overlaps with one of these reserved terms.

## `Connector`

`Connector` belongs to the Workflows domain. When adding a new Workflows component,
use `Connector` / `connector` freely — that is the reserved name for that domain.
